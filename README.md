# طقسي — mywather

تطبيق طقس عربي يعرض حالة الطقس والتوقعات لأي مدينة، مع قسم مخصص للإنذارات الرسمية السعودية الصادرة عن المركز الوطني للأرصاد.

## المصادر

- توقعات الطقس: Open-Meteo.
- الإنذارات السعودية: المركز الوطني للأرصاد.

> المؤشرات المستخرجة من التوقعات ليست إنذارات رسمية. عند تعذر الاتصال بالمصدر الرسمي، يوجّه التطبيق المستخدم إلى خريطة الإنذار المبكر.

## التشغيل

افتح `index.html` في المتصفح. يتطلب اتصالاً بالإنترنت لجلب البيانات المباشرة.
